SYSTEM · ผู้เล่น อนาลิธ
แพ็กเกจเว็บแอปติดตั้งบนมือถือ (PWA)

วิธีติดตั้งบน Android
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยังโฮสต์ที่รองรับ HTTPS เช่น GitHub Pages หรือ Netlify
2. เปิด URL ของเว็บแอปด้วย Chrome บนมือถือ
3. แตะเมนู ⋮ แล้วเลือก “ติดตั้งแอป” หรือ “เพิ่มลงในหน้าจอหลัก”
4. เปิดใช้งานจากไอคอน SYSTEM บนหน้าจอได้เลย

หมายเหตุ
- ต้องเปิดผ่าน HTTPS หรือ localhost จึงจะติดตั้งแบบ PWA และใช้งานออฟไลน์ได้
- ข้อมูลเกมเดิมเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น หากเปลี่ยนเบราว์เซอร์/ล้างข้อมูลเว็บไซต์ ข้อมูลอาจไม่ตามไปด้วย
- Google Fonts ยังต้องใช้อินเทอร์เน็ตในครั้งแรกที่โหลดฟอนต์
